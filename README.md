## プレビュー機能

- 画面左下 **PREVIEW** → 「災害時の表示を試す」で、段階ごとの見え方を再現できます。震度4・大雪＝全ページ上部のお知らせ帯のみ／震度5弱＝TOPを「状況確認中」に切替／震度5強以上＝TOPを強い表示に切替（以上は気象庁の情報による自動切替の想定）／手動：供給停止＝担当者が出す確定情報。URLでも切り替わります：`?level=4`・`5-`・`5%2B`（5強以上）・`snow`・`manual`・`off`。旧URLの `?emergency=1` は `manual`、`?emergency=0` は `off` と同じです。
- **担当者画面（スマホ用デモ）** `admin.html`：PREVIEW パネルのボタンから開きます。災害時にガス会社の担当者がスマホで使う画面のデモで、①表示段階の手動切替 ②お知らせの投稿（定型文・PDFや写真の添付・公開前の確認）③地区ごとの供給状況の更新 ④操作の履歴 ができます。公開すると `emergency.html` の「供給状況」と「当社からのお知らせ」に反映されます。デモでは内容を**その端末のブラウザ（localStorage）にだけ**保存し、どこにも送信しません（ログインも何を入れても進みます）。写真はブラウザ内で長辺1600pxに縮小し、位置情報（EXIF）を除いてから保存します。履歴タブの「デモの内容をすべて消す」で元に戻せます。
- フォームはすべてデモ動作（送信すると完了メッセージを表示するだけ）です。
- 電話番号リンクはどの端末でも「電話をかけますか？」の確認を挟みます。

## 構成

```
index.html …           生成物（編集しない）
assets/style.css       スタイル
assets/site.js         メニュー・緊急モード・フォームデモ
admin.html             担当者画面のデモ（手書き。build.py の生成対象外）
assets/admin.css, admin.js  担当者画面のスタイルと動作
assets/img/*.svg       ロゴ／街並みイラスト／メーター図解／エリアマップ
tools/layout.html      共通ヘッダー・フッター
tools/pages/*.html     各ページ本文（1行目にタイトル等のメタ）
tools/build.py         pages + layout → ルートにHTMLを生成
```

ページを編集したら:

```bash
python3 tools/build.py
```

## 本番化にあたって決めること

- 実際の電話番号・住所・料金表・約款PDF・写真
- フォームの送信先（メール通知サービス／Google Apps Script 等）
- 緊急表示の自動切替トリガー（気象庁 地震情報の受信条件）と更新権限
- 埋設管照会の認証方式とログの保管
- SNS アカウントURL
